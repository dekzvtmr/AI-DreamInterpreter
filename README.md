# AI Интерпретатор снов

Веб-приложение для психологической интерпретации снов, созданное на хакатоне.

## 🛠️ Требования и установка

### Необходимое окружение:
- **Python 3.10.x** (обязательно эта версия!)
- **Виртуальное окружение** (рекомендуется)
- **Ollama** с моделью `qwen2.5:0.5b`

### Пошаговая установка:

1. **Создай виртуальное окружение:**
   ```bash
   python3.10 -m venv venv
   source venv/bin/activate  # для Linux/Mac
   # или
   venv\Scripts\activate     # для Windows
   ```
   Если команда python3.8 не распознаётся, укажите полный путь к интерпретатору (например, /usr/bin/python3.8).

2. **Установи зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запусти Ollama в отдельном окне:**
   ```bash
   ollama pull qwen2.5:0.5b
   ollama serve
   ```

4. **Запусти приложение:**
   ```bash
   python app.py
   ```

## Стек технологий
*   Backend: Flask
*   AI: Ollama с моделью qwen2.5:0.5b
*   Распознавание речи: SpeechRecognition
*   Синтез речи: gTTS

## Установка и запуск
1. Установите Ollama: https://ollama.ai/
2. Скачайте модель: `ollama pull qwen2.5:0.5b`
3. Установите зависимости: `pip install -r requirements.txt`
4. Убедитесь, что запущен Ollama сервер.
5. Запустите приложение: `python app.py`
6. Откройте http://localhost:5000
